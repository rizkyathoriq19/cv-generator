## Missing skill-group warning

`missing_skill_achievements_warn_only_for_leading_structures` proves the
functional and combination warnings appear when no skill group has an
achievement bullet, reverse chronological does not warn, and `export_problem()`
stays `None` — the warning never blocks export. The warning is returned in the
export acknowledgement and shown in the existing warning list after export; it
is not a new mandatory field or generated claim.

## Review findings disposition (code-review v1)

| Finding | Disposition |
| --- | --- |
| Functional compact employment could render an entry whose only content is location or bullets as an empty row, and a blank `WORK EXPERIENCE` heading when it is the only entry | **Fixed** — `roles_shown` filters compact-invisible entries before the section and row render; `functional_hides_entries_with_no_compact_fields` fails if the blank heading returns. The empty-row path is covered by the filter, not observable in extracted text. Re-review v2 confirmed the original finding resolved. |
| Warning is computed only at export, after the PDF is written | **Accepted local limit** — the child ticket asks for a warning, not a pre-export gate; the export acknowledgement is that warning channel. A pre-export warning would need a new command or duplicated frontend rule. |
| `has_skill_achievements` is CV-global, so one evidenced group suppresses the warning for another empty group | **Accepted reading** — the ticket's mass-noun wording ("missing skill-group achievements") is satisfied when at least one group supplies evidence; per-group warnings are not requested. Schema wording changed to "when no skill group has an achievement bullet." |
| Structure taxonomy restated in Rust, Typst, TypeScript, and serde; warning name hand-rolled; test scaffold duplicated; cache identity passed as positional args; evidence test renders twice | **Accepted judgement calls** — no documented coding standard exists, Rust and Typst cannot share constants, and the duplication is bounded. Not changed in this slice. |
