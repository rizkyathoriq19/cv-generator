# 05 — Duplicate CVs and separate interface/content languages

**What to build:** A job seeker duplicates a CV for another application or manual translation, selects Indonesian or English content headings, and changes interface language without mutating any CV.

**Blocked by:** 04 — Switch between all three structures without losing content.

**Status:** implemented on `ticket-05-independent-copies-and-languages`; code/PDF checks and the application-level run are recorded in [ticket 05 evidence](../../evidence/ticket05/README.md). Runtime behaviour unchanged by later package slices.

**Proposed triage:** ready-for-agent after approval. Execution still requires explicit implementation authorization.

**Story coverage:** US-26, US-27, US-28, US-29.

- [x] Duplicate any project as an independently identified CV including all content, structure, and selected content language; edits to either copy never affect the other. — `duplicate_is_an_independent_copy_of_content_structure_and_language` writes a source, duplicates it, edits each side, and reads both back: the copy gets a new lowercase-hex id and every field, and each later save writes only its own file.
