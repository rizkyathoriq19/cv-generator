# Show the generated PDF rather than a parallel preview layout

Embed Typst through Rust and bundle PDF.js to preview the actual generated PDF, rather than maintain a separate HTML approximation that can disagree about pagination. Reuse that same artifact for export when it matches the current content revision; discard stale rendering results and never silently export an older revision as current. Export identity is the render input itself — CV data, selected structure, and content language — because that input *is* the current revision, so a stale client counter can never export different bytes; the render counter only orders concurrent renders and labels the preview. This accepts the typesetting and viewer dependencies in exchange for avoiding a custom pagination engine and parallel layouts; application-controlled templates, bundled licensed fonts, and restricted compiler resource access preserve offline operation and the plain-data input boundary. Platform compatibility, text extraction, responsiveness, and preview/export identity remain implementation verification gates, not established capabilities.
